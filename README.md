## Usage
- Left Click to zoom in
- Right Click to zoom out

## Building
- With IDE: Click Run
- Without IDE: run `cmake -B build` and then `cmake --build build` in the project folder directly

### Dependencies
## Fedora

- `SDL2-devel`
- `SDL2_image-devel`
- `glm-devel`
- `freetype-devel`
- `openal-soft-devel`
